Digital Store — интернет-магазин цифровой техники
===================================================

PHP 8 + MySQL/MariaDB + чистый CSS, без фреймворков.

------------------------------------------------------------
Требования
------------------------------------------------------------
- PHP 8.0+ с расширениями mysqli, mbstring
- MySQL 5.7+ или MariaDB 10.3+
- Любой веб-сервер (Apache, nginx, встроенный сервер PHP)

------------------------------------------------------------
Установка
------------------------------------------------------------
1. Скопируйте папку проекта в корень веб-сервера
   (например, в htdocs/ у XAMPP или в /var/www/html у LAMP).

2. Импортируйте файл dump.sql:
   - Через phpMyAdmin: выберите вкладку «Импорт» → выберите dump.sql
     (база digital_store создаётся автоматически).
   - Через консоль:    mysql -u root -p < dump.sql

3. Откройте db.php и при необходимости укажите свои настройки
   подключения (DB_HOST / DB_USER / DB_PASS / DB_NAME).
   По умолчанию используются переменные окружения или localhost/root.

4. Запустите сервер и откройте сайт:
       http://localhost/

   Для встроенного сервера PHP:
       php -S 127.0.0.1:8000

------------------------------------------------------------
Структура файлов
------------------------------------------------------------
/                      — публичная витрина
  db.php               — подключение, общие функции, шапка/подвал
  index.php            — каталог + фильтры + поиск
  product.php          — карточка товара + отзывы
  cart.php             — корзина
  checkout.php         — оформление заказа
  register.php         — регистрация
  login.php            — вход
  logout.php           — выход
  account.php          — личный кабинет
  image.php            — отдача изображений из BLOB
  style.css            — стили витрины

/admin/                — административная панель
  login.php            — вход админа
  logout.php           — выход
  index.php            — дашборд (KPI, аналитика)
  products.php         — список товаров
  product_edit.php     — редактирование товара (с загрузкой фото)
  categories.php       — категории (CRUD)
  brands.php           — бренды (CRUD)
  users.php            — пользователи (CRUD)
  orders.php           — заказы
  order_view.php       — карточка заказа (смена статуса)
  reviews.php          — отзывы (модерация)
  admins.php           — администраторы (CRUD)
  admin.css            — стили админки

dump.sql               — полный дамп БД с данными и BLOB-фото
README.txt             — этот файл
Пояснительная_записка.docx — пояснительная записка к диплому

------------------------------------------------------------
База данных (8 таблиц)
------------------------------------------------------------
- categories  (16 записей) — категории с иконками и порядком
- brands      (18 записей) — бренды
- products    (28 записей, BLOB-фото) — товары с реальными
                                       фотографиями из Wikimedia
- users       (16 записей) — покупатели
- admins      (3 записи)   — администраторы
- orders      (18 записей) — заказы
- order_items (35 записей) — позиции заказов
- reviews     (18 записей) — отзывы

------------------------------------------------------------
Возможности витрины
------------------------------------------------------------
- Сквозное мега-меню по 16 категориям;
- Поиск по названию, модели, описанию;
- Фильтры (категория, бренд, цена, память) и сортировка;
- Корзина в сессии (добавление, изменение, удаление);
- Регистрация, вход, личный кабинет с историей заказов;
- Отзывы от авторизованных покупателей;
- Адаптивная вёрстка для мобильных устройств.

------------------------------------------------------------
Возможности админки
------------------------------------------------------------
- Полный CRUD по всем таблицам;
- Загрузка фотографий товаров в БД (BLOB) прямо из веб-интерфейса;
- Управление заказами и сменой статусов;
- Дашборд с KPI и аналитикой продаж;
- Защита от удаления связанных записей (внешние ключи).

------------------------------------------------------------
Безопасность
------------------------------------------------------------
- Подготовленные выражения (защита от SQL-инъекций);
- Экранирование вывода (защита от XSS);
- Раздельная сессия пользователя и администратора;
- Проверка прав на каждой защищённой странице.

Пароли в БД хранятся в открытом виде — это сделано осознанно,
по требованию учебной задачи, чтобы продемонстрировать работу
с БД на занятиях.
